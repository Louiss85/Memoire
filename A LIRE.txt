.ipynb_checkpoints : Contient des sauvegardes de chaque notebook

Dicopoitevin 
	dicopoitevin adapté : Base de données dicopoitevin ne comprenant que les verbes et leur radical
	dicopoitevin brut : Base de données dicopoitevin sans modification
	dicopoitevin glose : Base de données dicopoitevin ne comprenant que les verbes et toutes les informations associées
	dicopoitevin verbes : Base de données dicopoitevin ne comprenant que les verbes et sa/ses glose(s)

Emprunts 
	Poitevin : Scripteurs poitevins
		Correspondances : Listes d'emprunts trouvés dans les textes des locuteurs
		Epuration : Liste des formes verbales ou non sans les terminaisons verbales
		Non-correspondances : Listes des termes pour lesquels le script n'a pas trouvé de correspondance
	Saintongeais : Scripteurs saintongeais
		...
		
Flexions
	Lexiques 
		Formes déduites : Lexique de chaque scripteur avec la fréquence d'apparition des formes attestées
		Formes glosées : Lexique de chaque scripteur avec les gloses
		Formes régulières : Lexique de chaque scripteur contenant seulement les verbes du premier groupe
		Reg + Ireg : Lexique complet de chaque scripteur avec verbes du premier groupe et irréguliers
	FFPS 2.0 : Lexique complet

Irréguliers
Pour chaque verbe irrégulier : 
	Localisation formes : Cartes regroupant la localisation des scripteurs pour lesquels une terminaison est attestée
	Terminaisons : Terminaisons de chaque scripteur
	
	Pour dire, faire et voir : 
	Pré-tri
		Poitevin : Liste des formes pré-sélectionnées pour récupérer les terminaisons des scripteurs poitevins
		Saintongeais : Liste des formes pré-sélectionnées pour récupérer les terminaisons des scripteurs saintongeais
Lexique générés : Lexique des verbes irréguliers pour chaque scripteur

Lexiques
	Lexiques adaptés : Contient les lexiques FR : GLAFF, LEFFF et Analog uniformisés
	Lexiques radicaux infinitifs : Contient les lexiques FR avec seulement leurs lemmes + le fichier Infinitifs qui regroupe les trois lexiques FR
	Lexiques vierges : Contient les lexiques FR sous leur format d'origine : GLAFF, LEFFF et Analog
	Lexique gloses1 : Fusion des trois lexiques FR 
	Lexique gloses2 : Fusion des trois lexiques FR avec corrections (Ex : Ajout des accents sur les participes passés)
	
Localiser locuteurs
	Localisation terminaisons : Carte regroupant les localisations des scripteurs pour qui une forme est attestée
	Localisation infinitifs : De même pour les terminaisons infinitives
	Terminaisons : Liste des terminaisons des verbes du premier groupe de chaque locuteurs
	CarteFrontieres : Carte vierge avec la frontière du territoire linguistique
	carteLocuteurs : Carte regroupant l'ensemble des scripteurs du corpus
	occurences : Données statistiques sur le nombre de scripteurs qui attestent telle ou telle terminaison

Notebooks : Liste des notebooks contenant les scripts 

Statistiques
	correlations : Corrélations sur les fréquences d'apparition des formes attestées basées sur le temps, mode, personne et le nombre
	correlations_sans_subj_inf_imp : De même, sans compter les infinitifs, le subjonctif et l'impératif
	frequences : Fréquence d'apparition de chaque forme verbale attestée
	indice_variabilité_scripteur : Indique de variabilité intra-scripteur 
	person_number : Fréquences d'apparition des formes attestées basées sur la personne et le nombre
	person_number_sans_subj_inf_imp : De même, sans compter les infinitifs, le subjonctif et l'impératif
	supralemmes_frequences : Fréquence d'apparition de chaque supralemme 
	tense_mode : Fréquence d'apparition des formes attestées basées sur le temps et le mode 
	tense_mode_sans_subj_inf_imp : De même, sans compter les infinitifs, le subjonctif et l'impératif
	
Test de Levenshtein : Contient le fichier test qui a permis de déterminer si le test de Levenshtein était pertinent ou non

Textes locuteurs 
	Paires graphiques : Liste des paires graphiques

			Correspondances comptage : Seulement à but statistique, inutilité dans le Mémoire

		Textes bruts : Textes de chaque scripteur récupérés tel quel
